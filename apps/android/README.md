# OpenPush Android companion shell

This Kotlin/Compose companion captures new SMS broadcasts and can submit
permitted SMS commands through Android's carrier API. It is not the default SMS
app: it requests only `RECEIVE_SMS` and `SEND_SMS`, never `WRITE_SMS`, and has
no `READ_SMS` permission or inbox-history scan.

SMS uses only the current default SMS subscription. If that subscription changes
or disappears, a command for the old route remains pending and is never sent
through another SIM. MMS is unsupported and is never downgraded to SMS; ordinary
apps have no general RCS inbox or send API. A usable physical carrier route still
depends on granted SMS permissions and a current default SMS SIM; carrier and
hardware validation are separate from unit or emulator results.

Generated Kotlin from `openpush-mobile-bindings` belongs under
`app/src/main/java` and is generated by the commands in that crate's README.
From the repository root, install JDK 17, the Android command-line tools,
`platform-tools`, `platforms;android-35`, `build-tools;35.0.0`, and
`ndk;27.2.12479018`. Set `JAVA_HOME` to JDK 17 and `ANDROID_HOME` to that SDK.
Then generate and package the native library:

```sh
rustup target add aarch64-linux-android
export ANDROID_NDK_HOME="$ANDROID_HOME/ndk/27.2.12479018"
infra/compose/verify-android-native.sh
```

The packaged Rust library and APK native ABI are ARM64 only (`arm64-v8a`). Build
and run the JVM-hosted checks with:

```sh
cd apps/android
./gradlew :jvm-smoke:run :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

With a connected ARM64 emulator or device, run the JNI instrumentation smoke:

```sh
cd apps/android
./gradlew :app:connectedDebugAndroidTest
```

The instrumentation smoke covers generated bindings, SQLCipher/crypto, capture,
reopen, and typed closed-handle errors. It does not validate live carrier SMS,
MMS, RCS, or physical-network behavior.
